# Third-party code and assets

Not redistributed here (install separately):

- **Isaac Gym Preview 4** — NVIDIA, proprietary license. https://developer.nvidia.com/isaac-gym
- **IsaacGymEnvs, TacSL branch** — NVIDIA, BSD-3-Clause. Provides `isaacgymenvs.tacsl_sensors` (the simulated GelSight) and the IndustReal peg asset `assets/industreal/urdf/industreal_round_peg_16mm.urdf`. https://github.com/isaac-sim/IsaacGymEnvs
- **reactive_diffusion_policy** — Han Xue, Wendi Chen, Yuan Fang, MIT. Only `reactive_diffusion_policy.model.diffusion.conditional_unet1d.ConditionalUnet1D` is imported. https://github.com/xiaoxiaoxh/reactive_diffusion_policy

Included in `sim/ur5_2f85_isaacgym/` (robot URDF and meshes, converted for Isaac Gym):

- UR5 meshes and description — ROS-Industrial `universal_robot`, BSD-3-Clause (`sim/ur5_2f85_isaacgym/LICENSE.meshes`).
- Robotiq 2F-85 meshes — from ElectronicElephant's `pybullet_ur5_robotiq`, BSD-3-Clause (`sim/ur5_2f85_isaacgym/LICENSE`).
- GelSight Mini housing mesh (`meshes/gs_mini`) — simplified geometry used for the sensor body; elastomer collision is a box/mesh generated by `make_prismatic_gripper.py` in the original workspace.

Included in `sim/objects/`: the wiping board and stage (`wipe_board*.obj/urdf`, generated by `make_wipe_board.py`), the socket stage and a ball used by the insertion environment. All written for this project.

Papers reimplemented (no code taken):

- ImplicitRDP — Chen et al., arXiv:2512.10946, 2025.
- Reactive Diffusion Policy — Xue et al., RSS 2025.
